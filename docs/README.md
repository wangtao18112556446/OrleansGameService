# 文档导航

本项目面向基于 Orleans 开发 MMORPG 的服务端开发者。规划中的能力不代表已经实现；当前可运行路径见根目录 [README](../README.md)。

| 文档 | 内容 | 维护时机 |
| --- | --- | --- |
| [开发路线](ROADMAP.md) | 当前能力、功能范围、阶段验收 | 范围或阶段状态变化时 |
| [近期待办](BACKLOG.md) | 优先级、依赖、任务验收 | 任务开始、完成或发现新风险时 |
| [架构](ARCHITECTURE.md) | 依赖、状态归属、扩展方式、一致性 | 模块职责或调用关系变化时 |
| [工程规范](ENGINEERING.md) | 代码、测试、兼容性、交付要求 | 工具链和协作规则变化时 |
| [服务器权威移动](gameplay/movement.md) | 移动预算、时间、恢复和内容配置 | 移动规则或状态语义变化时 |
| [实时协议错误码](protocol/errors.md) | 操作号、移动及报文错误的重试语义 | 协议错误或重试规则变化时 |
| [贡献指南](../CONTRIBUTING.md) | 本地验证、提交和评审流程 | 开发入口变化时 |
| [ADR 0001](adr/0001-framework-direction.md) | 通用核心与玩法模块的演进决策 | 由新 ADR 替代，不覆盖历史取舍 |

后续按功能落地补充以下专题；这些路径当前不代表已有文档：

- `protocol/`：HTTP、MessagePack 消息表、错误码、操作重试、会话恢复与版本矩阵。
- `gameplay/`：移动、战斗、属性、物品、任务、AI 的规则、不变量和内容样例。
- `guides/`：从空项目接入框架、开发模块、导入和发布内容、运行示例客户端。
- `operations/`：配置、部署、监控、迁移、备份恢复、故障处置和压测报告。
- `adr/`：状态所有权、协议演进、跨 Grain 流程和部署拓扑的决策记录。

文档应区分“当前行为”“拟议设计”“验证结果”。每个专题给出代码入口、正常/失败示例和限制；不能只描述理想流程。重大行为变更与文档在同一 PR 交付。
